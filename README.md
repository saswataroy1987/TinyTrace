# TinyTrace

## Current direction: Phase B v2

The current goal is high-quality dense video event captions and timestamps using
MobileCLIP. The v1 character-decoder run is preserved as a baseline. The planned
v2 architecture uses a dedicated temporal event detector plus a pretrained
FLAN-T5 Small caption decoder.

Read the complete design and staged implementation plan in
[README_PHASE_B_V2.md](README_PHASE_B_V2.md).
